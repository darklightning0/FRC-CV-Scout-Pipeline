# Hunter Eyes

FRC strategy & scouting app (2026 REBUILT) with computer-vision match telemetry. Deployed as **Hunter Eyes** at [huntereyes.netlify.app](https://huntereyes.netlify.app).

Originally based on the Maneuver-2026 / maneuver-core scouting framework; product branding and logos are Hunter Eyes.

## Quick start

```bash
cd web
npm install
npm run dev
```

See `ROBOTDETECTOR.md` and `../COMPETITION_CV.md` for CV pipeline + cloud sync setup.
